# x650_reconstruction

Offline workstation tool. Lives outside the ROS workspace and uses its own environment, separate from flight software (plan section 15).

**Milestone:** M5

**Responsibility:** Post-flight camera/trajectory refinement, dense geometry, meshing and texturing orchestration (COLMAP + OpenMVS candidate).

**Main output:** Metric mesh, point cloud, reconstruction manifest.

See `docs/3D_SLAMer_TechnicalPlan.md` sections 6 and 11.
